# 会话派单与动态并行展示专项

桌面用例使用「Orchestra-体验」工作区的办公 CSV，在原生 DSH 会话直接输入。桌面回执来自实际模型和真实运行账本。视图用例使用可控运行数据，在组件和 Chromium 中重现等待、旧尝试、切换任务及焦点迁移。
