### 怎样理解结果

- **符合**表示该行操作在所列环境达到预期。专项失败后修复通过的项目保留前后结果。
- **部分符合**表示行内还有一个设计条件或环境缺少验证。例如安装包能在隔离宿主启用，首次使用者从干净桌面安装并在同名历史中识别本次成果仍需完整观察。

- **待验证**表示没有满足该场景的执行凭据，或该行仍是未采纳的设计提议。
