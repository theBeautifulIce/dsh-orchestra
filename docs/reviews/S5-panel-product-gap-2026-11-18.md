# S5 产品展示与底层契约差距

对照本仓库 `panel-v2.html`、当前 S5 读写路径及《对比项目不足分析》。比较对象是本仓库的实现与产品目标。外部项目仅作为此前分析的背景。

| 领域 | 本轮已接入 | 仍待完成的能力 |
| --- | --- | --- |
| 总览 | 从 SQLite 同一读快照统计工作台四列、开放的决定和待核实项。显示最近账本活动、已登记流程和当前使用量 | 主脑分派日志、执行主体拓扑和全局暂停需要实际宿主控制契约 |
| 任务工作台 | 同一查询驱动看板、流程与列表。支持状态、时间、来源筛选、归档和取回。可从已发布流程创建任务。右侧保留步骤、结果、证据与运行活动 | 自然语言任务入口、任务简报、工作流选择与计划质量门仍属 M1。定时、事件、持续是已记录的启动来源，实际调度须由对应宿主入口接入 |
| 工作流 | 固定版本的依赖图和运行步骤可以从任务查看。设计画布有节点检查器、版本和最近 50 次运行，可打开指定运行 | 运行关键路径、阻塞原因归并、定时触发策略管理与实际触发验证 |
| 决定与风险 | 待处理和历史分开，可查优先级、原因、处理人。执行前审批绑定到具体节点、修订和已有内容哈希，支持策略要求的二次确认。待核实支持核对合格系统证据后记账 | 其他决定类型的动作契约、跨任务与执行主体的权限治理。证实未发生和人工裁决结算仍需专门面板 |
| 运行与事件 | 新增「发生过的」及任务运行活动。事件来自同一账本，按序号倒序分页。原有 SSE 续传和轮询提供刷新 | 完整执行主体 Trace、工具耗时与等待窗口、旧事件缺失的关联字段、跨执行主体业务 ACK |
| 成果交付 | 任务结果可查运行终态和登记产物，按节点查看已验证的工具证据和人工签认 | 产物版本、生成节点与验收状态、内容预览或受认证下载、可追溯的交付说明。当前资料仅保证已登记的元数据可见 |
| 记忆 | 已配置受控记忆宿主时，用户可从已成功任务的结果发起整理并凭回执进入批次页。沿用现有评估、审批与写入恢复 | 在实际 DSH 桌面宿主验证该入口与部署配置 |
| 执行主体与协作 | 运行、节点、执行会话、租约已有底座 | 持久协作请求、接收与采纳、业务 ACK、可发现的执行主体生命周期。按工作区做权限与预算治理尚属后续路线 |
| 执行模型派发 | 可信推荐回调、宿主模型清单、派发代次与实际模型确认已接入执行主链和步骤展示 | 实际 DSH 模型清单、会话模型设置与真正的主脑复杂度评估仍须在宿主联调。现有默认桥对旧配置继续兼容 |

归档是独立的持久记录。归档请求使用认证主体和操作回执，状态变更与账本事件同笔写入，运行与历史仍可查。启动来源缺失时显示「来源未记录」。自治档位独立反映任务记录，风险审批仍由既有策略执行。

模型推荐须读取可信主脑已计算的复杂度，派发事务内的回调保持同步。宿主根据 `executor.spawn` 的 `modelRef` 创建会话，并从会话回读 `effectiveModelRef`。回读一致后才发送任务；缺少确认或不一致时阻塞本次派发。启用前先在实际 DSH 上验证候选模型和会话回读。

本轮预览使用隔离的 SQLite 演示数据和真实服务接口。Chrome 在 1366×900 与 1600×1000 验证同屏四列、右栏、产物与账本证据。浏览器也验证了状态、日期、来源筛选，归档取回，流程运行跳转，真实新建任务，以及二次审批进入历史。套件 `pnpm check` 通过，111 个测试文件，1,353 项通过、2 项跳过。正式 DSH 宿主部署与 G5 独立验收仍待完成。
