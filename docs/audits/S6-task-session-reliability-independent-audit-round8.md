### 原题 T10 暴露的停止故障

303 字的 T06 原题只替换任务名后，正式桌面成功建立了 T10。两名代理有一条真实的待回应请求。面板在请求建立后 135 毫秒确认停止，双方随后各留下当次执行的宿主停止回执，信箱在截止时间前把原请求关为不可再回应。完整退出并重开同一隔离桌面后，同库服务代次由 3 升至 4。原运行仍显示运行中，两个步骤仍为正在停止，两者均无动作截止时间，审批中心也没有卡片。该结果阻断专项验收。[T10 实机记录与标识](../reviews/S6-session-desktop-case-matrix.md)

根因是取消结果未知时，普通执行步骤可以进入 `stopping`。执行器会持久化停止回执，维护扫描却只从有截止时间的 `stopping` 生成审批，另一条恢复路径只处理 `blocked_post`。两条规则合起来遗漏了这一组历史和新运行。旧任务无法完成停止并在来源会话发出终态通知。新任务可独立运行，也不能消除这项故障。
