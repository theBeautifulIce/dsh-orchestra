本轮将同类故障的处理放在无工具规划子会话。计划或流程的一轮确实以上限结束时，先核对模型路由和思考设置、来源会话仍在线，再让同一规划者用精简字段重写完整结构。纠正消息没有附上原题和截断正文，也没有重新创建任务、代理或审批。规划者仍会携带自身会话历史。两个回合共享原阶段时限，单次上限仍为 8192，第二次也截断则返回失败。额度、拒绝访问、连接异常和返工等场景走各自原有处理。

只有第二次请求之后产生的新事件可以构成补交结果。若没有新正文、路由错误或新内容未通过原有规划结构与权限校验，均不能进入执行。执行报告的一次无工具格式补交也采用同样的新事件范围。输入简短的任务若首轮成功，只发生一个模型回合。
