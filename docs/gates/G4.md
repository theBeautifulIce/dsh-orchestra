## 本批定值

| 项 | 值 | 理由 |
| --- | --- | --- |
| `SUBWORKFLOW_DEPTH_MAX` | 2 | 与 S3 一致：子流程嵌套超过两层即拒 |
| `operation_id` | UUIDv7（小写带连字符） | 全局命令身份是协议硬约束，HTTP 与命令层同一正则 |
| `publish_note` | 1–500 字必填 | 发布说明是版本审计口径，不留空 |
| `WORKFLOW_DOC_MAX_BYTES` | 1 MiB | 超限直接 413，不进 issue 列表 |
| task_local 归属 | 预留任务 + 事务内 CAS | owner 必须是服务端预留且未消费；根入口禁起，只允许子流程引用 |
