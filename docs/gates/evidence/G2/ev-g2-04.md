# ev-g2-04

- 必过项：G2-04 取消后不产生新 attempt
- 用例：`tests/integration/g2.spec.ts` 的「取消后不产生新 attempt」与「G2-04 已完节点取消不动状态、不产生新 attempt」，另见 `tests/cancel.spec.ts` 的「done 取消保持 done」「重复取消只立一次围栏」。
- 复现：`pnpm vitest run tests/integration/g2.spec.ts tests/cancel.spec.ts`
- 断言口径：执行中被取消落到 timing_out 且围栏 armed，attempt 保持 1，node_runs 里该节点只有一行；已 done 的节点再取消返回 already_stopped、next_status=done，状态不被改回 timing_out（审计 F-07：取消的 CAS 之前没有 status 条件，done 能被改写）。
