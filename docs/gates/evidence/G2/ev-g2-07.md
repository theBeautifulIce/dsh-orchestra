# ev-g2-07

- 必过项：G2-07 S2 加载 parallel 被拒
- 用例：`tests/integration/g2.spec.ts` 的「S2 加载 parallel 被拒」，生产口另有 `tests/routes.spec.ts` 的「加载工作流 → 拿租约 → 上报 → 三条路都进服务层」证明加载路由真的接到 WorkflowCatalog。

- 断言口径：S2 阶段 assertDefinitionAllowed 遇到 parallel 节点抛 FORBIDDEN（阶段能力位不含 parallel，规格 2.4），HTTP 加载路由回 403；agent 节点在 S2 可加载，加载后节点判定条件按模板基线合并。
