# ev-g2-05

- 必过项：G2-05 终态必带证据
- 用例：`tests/integration/g2.spec.ts` 的「终态必带证据」，另见 `tests/policy.spec.ts` 的证据门用例与 `tests/apply-report.spec.ts` 的强证据校验。
- 复现：`pnpm vitest run tests/integration/g2.spec.ts tests/policy.spec.ts tests/apply-report.spec.ts`
- 断言口径：不带 evidence 的 done 上报 accepted=false、registry_state=rejected、节点停在 dispatched；弱证据（tool_result）或缺少 requiredHashes 时返回 verification_too_weak，只有 run_tool 强证据且命令哈希核对通过才允许进 done。
