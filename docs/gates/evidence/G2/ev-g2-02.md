# ev-g2-02

- 必过项：G2-02 重复上报只落一次
- 用例：`tests/integration/g2.spec.ts` 的「重复上报只落一次」与「G-03 同一个 report_id 上报两次只落一次」。
- 复现：`pnpm vitest run tests/integration/g2.spec.ts`
- 断言口径：同一 report_id 第二次上报 accepted=false、registry_state=replayed，report_applied 事件仍然只有 1 条。
- 重放规则（审计 F-04 之后）：重复上报要过三道——attempt 对得上、节点事件链不断、且该 report 的 report_seq 是该 node_run 的队头；任一不符分别返回 replay_chain_broken / replay_not_head，不会被当成已应用吞掉。
