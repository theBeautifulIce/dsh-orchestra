# ev-g2-01

- 必过项：G2-01 单节点 queued 到终态一条路径
- 用例：`tests/runtime.spec.ts` 的「queued → dispatched → started → verifying → done，落强证据」走生产装配（createOrchestra → runNode），`tests/integration/g2.spec.ts` 的「单节点 queued 到终态一条路径」走命令层。
- 复现：`pnpm vitest run tests/runtime.spec.ts tests/integration/g2.spec.ts`
- 断言口径：生产路径里 runNode 依次拿租约、起执行器、跑只读工具、核命令哈希、上报 started、转 verifying、上报 done；命令层里 dispatched→started→verifying→done 三次上报每次都 applied，终态 node_runs.status=done，report_applied 事件 3 条。
- 这一版补的口子：审计指出 S2 的命令与执行器没有接入生产路径，之前只有单元测试自证。现在 `src/index.ts` 装配 `createOrchestra`，`src/service/server.ts` 挂四条第命令路由，本证据里 runtime 用例走的就是这条真实装配。
