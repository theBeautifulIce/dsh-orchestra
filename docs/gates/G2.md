## 本批定值

规格未定的参数在本批定值，S1 已定的沿用，不新增全局未决项。

| 项 | 值 | 理由 |
| --- | --- | --- |
| 租约时长 `execution.lease_ttl_ms` | 30000 | 允许连续两次心跳丢失仍不误判过期，又不至于让被取消的节点长时间占着 attempt |
| 心跳间隔 `execution.lease_renew_interval_ms` | 10000 | 租约的三分之一，留两次重试余量 |
| 动作超时 `execution.action_timeout_ms` | 120000 | 与规格 17.2 的 `verify_timeout_ms` 同量级 |
| 取消宽限 `execution.cancel_grace_ms` | 30000 | 规格 4.5 明写 30 秒，照抄不另定 |
| 桥缓冲上限 / 高水位 | 8388608 / 4194304 字节 | 规格 7.3 与 17.2 配置样例一致 |
| 桥 spill 目录 | `storages/dsh-orchestra/bridge-spill/` | 放插件存储根下，跨重启可查，不落进仓库工作区 |
| 证据强弱来源标记 | `run_tool` 为强、`tool_result` 为弱 | 规格 4.7 |
| `report_registry.report_seq` | 每个 node_run 从 1 起自增 | 队头重放按 seq 取最小值（规格 4.2） |
| 写队列上限 | 1000 条，满了 503 并记 warning | S1 已定，本批沿用 |
| 事件与证据保留期 | 回执 7 天，事件不自动清理 | S1 已定，本批沿用 |
